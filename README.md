# Network+ Study App 🚀

A lightweight, beginner-friendly desktop application built to help you drill CompTIA Network+ concepts (Chapters 1-6). 

Instead of just memorizing raw facts, this app breaks down complex networking concepts (like the OSI model, DNS, and Subnetting) using simple analogies. It also includes an interactive flashcard driller to help you prep for the exam.

## Features
*   **Chapter Summaries:** Plain-English breakdowns of core Network+ topics.
*   **Interactive Flashcards:** Randomized Q&A driller to test your knowledge.
*   **Zero Dependencies:** Built entirely with Python's standard library (`tkinter`). No massive installs required.

## How to Run
You will need Python 3 installed on your system. 

1. Clone or download this repository.
2. Open your terminal or command prompt.
3. Navigate to the folder containing the app.
4. Run the following command:

   ```bash
   python3 network_study_beginner.py
